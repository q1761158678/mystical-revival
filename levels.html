DOC-LV-000

等级概述

总部将所有已发现的诡异存在按危险程度划分为六个等级。等级评定综合考虑厉鬼的攻击性、影响范围、收容难度以及对抗手段的有效性。每一位驭诡者在执行任务前，必须充分了解目标诡异等级及相应的安全规范。

重要提示：等级评定并非一成不变。部分厉鬼在特定条件下（如满月、特定日期、接触特定物品）会出现能力波动，实际威胁可能高于评定等级。驭诡者须始终保持高度警惕。
最高危
S

S级 · 灭世级

最高警戒
威胁程度：可能导致大规模人员伤亡，威胁城市级安全
影响范围：城市级 / 区域级
收容难度：极高
对抗手段：需多支驭诡者编队协同作战，动用特级收容装备
已知数量：3只（已收容）

S级诡异是总部目前掌握的最高威胁等级。这类厉鬼通常具有极强的主动性、不可预测的攻击模式以及难以有效对抗的特殊能力。一旦S级厉鬼突破收容，将可能造成灾难性后果。

处置规范：S级事件须立即上报总部最高指挥中心，由总指挥亲自授权作战方案。所有参与行动的驭诡者须签署《高危任务知情同意书》。非Ω级权限人员不得查阅S级厉鬼的详细档案。
A

A级 · 危险级

高危
威胁程度：可造成多人伤亡，具有主动攻击性
影响范围：街区级 / 建筑级
收容难度：高
对抗手段：需专业驭诡者编队，配备标准收容装备
已知数量：12只（已收容） / 4只（处理中）

A级厉鬼具有较强的攻击性与特殊能力，能够在短时间内造成多人伤亡。这类厉鬼通常具有明确的攻击规律，但对抗难度较大。A级事件由各省级分部负责处置，必要时可请求总部支援。

B

B级 · 警戒级

威胁程度：具有攻击能力，可造成个别人员伤亡
影响范围：单栋建筑 / 局部空间
收容难度：中
对抗手段：2-3名驭诡者即可处置
已知数量：28只（已收容） / 9只（处理中）

B级厉鬼具有一定的攻击性，但攻击范围有限，通常需要特定触发条件。多数B级厉鬼具有可被利用的弱点。由市级分部负责处置。

C

C级 · 关注级

威胁程度：攻击性弱，主要造成心理影响
影响范围：单一地点
收容难度：低
对抗手段：1名驭诡者即可处置
已知数量：46只（已收容） / 4只（处理中）

C级厉鬼攻击性较弱，通常不会直接造成人员伤亡，但会通过心理暗示、幻觉等方式影响周围人员的精神状态。如不及时处置，可能逐步升级为B级。由区级分部负责处置。

D

D级 · 低危级

威胁程度：几乎无攻击性
影响范围：极小范围
收容难度：极低
对抗手段：标准收容程序即可

D级厉鬼能力微弱，多数仅能产生轻微的灵异现象（如物体移动、温度异常等）。虽然威胁较低，但仍需及时收容以防能力升级。由分部常规巡查队处置。

DOC-LV-EXT

灵异现象（非厉鬼类）

灵异现象是指由残留灵异能量引起的异常事件，不具备厉鬼的自主意识与攻击性。灵异现象通常范围有限、持续时间短，但如不加以控制，可能逐渐演化为厉鬼。

类型特征处置方式
声音型无法解释的声响、人声灵能净化装置
视觉型幻觉、影子异常、光影扭曲空间稳定剂
电子型电子设备异常运作灵能过滤装置
温度型局部温度骤降或骤升能量中和
空间型空间扭曲、不存在的房间/走廊空间封印术

DOC-LV-SAFE

驭诡者安全指南

一、任务前准备

1. 充分了解目标诡异的等级、能力特征与已知弱点。

2. 携带符合等级要求的收容装备与应急用品。

3. 确保通讯设备正常，与指挥部保持联络。

4. 告知队友自身的诡异能力类型与使用限制。

二、任务中注意事项

1. 切勿独自行动。至少两人一组，保持互相监视。

2. 如感到自身诡异能力出现异常波动，立即报告并撤离。

3. 不要试图驾驭任务目标之外的厉鬼。

4. 遇到无法理解的现象时，不要试图理解它——先撤离，再分析。

5. 注意观察队友的精神状态。如发现队友出现异常行为，立即报告。

三、任务后要求

1. 所有参与人员须接受心理评估。

2. 使用的诡异能力须记录备案。

3. 如出现能力异常或精神不适，须接受隔离观察。

4. 任务报告须在24小时内提交。

⚠ 最终警告：诡异的本质至今未明。任何自以为"理解"了诡异规律的人都已不在人世。保持敬畏，保持距离，保持理智。这是你能活着回来的唯一保障。
